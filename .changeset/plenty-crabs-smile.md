Ship `llms.txt` in the published package.

A single file an agent can read to learn what overlock is, when to call it, what
the nine rules mean, and what the JSON contract looks like — the same class of
agent-facing packaging that turned jscpd from a dormant CLI into one agents
reach for.

It says the thing that matters most in the imperative: if a HIGH finding
appears, fix the cause, not the check. Adding a suppression to make a check pass
without being asked is named as a non-fix.

`check:llms` keeps it honest, in `verify` and in CI. A doc that has drifted from
the code is worse than no doc — it is confidently wrong, to a reader with no way
to check — so the guard fails on a rule ID that no longer exists, on any
rule-shaped name that was never a rule, and on a command that was renamed.
