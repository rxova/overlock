# overlock logo

The package logo is a sewing machine stitching code brackets: keeping code from unraveling.
It uses a 64×64 viewBox, rounded strokes, and the same teal accent as the input package logos.

[logo.svg](./logo.svg) is the primary logo used in both READMEs and included in the published package.
[logo-sewing.svg](./logo-sewing.svg) preserves the original, unmirrored concept.
